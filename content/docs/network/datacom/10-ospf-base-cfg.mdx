## 基本概念

开放式最短路径优先（Open Shortest Path First，OSPF）协议是一种基于链路状态的内部网关协议（Interior Gateway Protocol，IGP），使用 SPF 算法，收敛速度快，适用于规模较大的网络。

OSPF 概述：

- 大中型网络上使用最为广泛的 IGP 协议
- 链路状态路由协议
- 无类（路由更新携带掩码，支持 VLSM/CIDR）
- 使用组播（224.0.0.5 和 224.0.0.6）
- 收敛较快
- 以开销（Cost）作为度量值
- 采用的 SPF 算法可以有效的避免环路
- 触发式更新（以较低的频率（每 30 分钟）发送定期更新，被称为链路状态泛洪）
- 区域的设计使得 OSPF 能够支持更大规模的网络
- 通过 LSA 的形式发布路由
- 不支持自动汇总，支持手动汇总
